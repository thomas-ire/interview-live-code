# Problem 3 — Get Password from Grid

Difficulty: Medium

## Problem statement

In this kata you are expected to recover a scattered password in a (m x n) grid. You'll be given directions to find all password pieces in the grid.

The grid contains pieces of the password to be recovered. Your initial position in the grid is marked with the character `"x"`. You'll receive directions on how to navigate and collect all the pieces.

The given directions consist of:
- **Movement only**: `left`, `right`, `up`, `down` — move to that direction without taking any character
- **Take and move**: `leftT`, `rightT`, `upT`, `downT` — take the character in that direction and move there (the "T" suffix means "take")

## Input / Output

- Input:
  - `grid` — 2D array (list of lists) containing characters, with one cell marked as `"x"` (starting position)
  - `directions` — list of strings containing movement instructions
- Output: string representing the collected password

## Examples

1) Example

```
grid = [
  ["p", "x", "m"],
  ["a", "$", "$"],
  ["k", "i", "t"]
]
directions = ["leftT", "downT", "rightT", "rightT"]

getPassword(grid, directions) // => "pa$$"
```

Explanation:
- Start at `"x"` (row 0, col 1)
- `leftT`: take "p" from left (0,0) and move there → password = "p"
- `downT`: take "a" from down (1,0) and move there → password = "pa"
- `rightT`: take "$" from right (1,1) and move there → password = "pa$"
- `rightT`: take "$" from right (1,2) and move there → password = "pa$$"

2) Example

```
grid = [
  ["a", "x", "c"],
  ["g", "l", "t"],
  ["o", "v", "e"]
]

x 1 ,y 0
x 1 ,y 1
directions = ["downT", "down", "leftT", "rightT", "rightT", "upT"]

getPassword(grid, directions) // => "lovet"
```

Explanation:
- Start at (0,1)
- `downT`: take "l" from (1,1), move there → password = "l"
- `down`: just move to (2,1), no character taken
- `leftT`: take "o" from (2,0), move there → password = "lo"
- `rightT`: take "v" from (2,1), move there → password = "lov"
- `rightT`: take "e" from (2,2), move there → password = "love"
- `upT`: take "t" from (1,2), move there → password = "lovet"

## Constraints & complexity

- Expected time complexity: O(d) where d is the number of directions (each direction is processed once).
- Expected space complexity: O(d) for storing the password string.
- The grid dimensions are m x n where m, n ≥ 1.
- The starting position "x" is always present in the grid.
- All directions are valid (won't go out of bounds).

## Hints

- Find the starting position "x" by scanning the grid.
- Use a position tracker (row, column) to track your current location.
- For each direction:
  - Calculate the target position based on the direction
  - If the direction ends with "T", collect the character at the target position
  - Move to the target position
- Use a dictionary/map to translate direction strings to coordinate changes:
  - `left`/`leftT`: col - 1
  - `right`/`rightT`: col + 1
  - `up`/`upT`: row - 1
  - `down`/`downT`: row + 1

## Suggested tests

- Basic example: grid with simple path
- Complex path: multiple direction changes
- Mixed movements: combination of take (T) and non-take movements
- Edge cases:
  - Single cell grid with just "x"
  - Empty directions list (no password collected)
  - Grid with special characters in password
- Boundary movements: directions that move along edges of the grid
- Long password: directions that traverse the entire grid
