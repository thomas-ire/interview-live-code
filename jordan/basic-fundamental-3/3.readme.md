# Problem 3 — Sum of Digits / Digital Root

Difficulty: Easy

## Problem statement

The digital root of a non-negative integer is obtained by repeatedly summing its digits until the result is a single digit. Given `n` (n >= 0), return its digital root.

## Input / Output

- Input: non-negative integer `n`.
- Output: integer in range 0..9 representing the digital root.

## Examples

- `16`     -> `7`  (1 + 6)
- `942`    -> `6`  (9 + 4 + 2 = 15 -> 1 + 5 = 6)
- `132189` -> `6`  (sum -> 24 -> 2 + 4 = 6)
- `493193` -> `2`  (sum -> 29 -> 1 + 1 = 2)

## Constraints & hints

- Simple iterative approach: convert to digits and sum repeatedly until single-digit. Complexity proportional to number of digits processed.
- Mathematical shortcut (O(1) time): for `n > 0`, digital root = `1 + ((n - 1) % 9)`. For `n == 0`, the result is `0`.

## Suggested tests

- Edge cases: `0` -> `0`, single digit numbers (`1..9`) map to themselves.
- Boundary examples: `9`, `10`, `99`, `1000000`.
